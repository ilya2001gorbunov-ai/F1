# F1 Календарь (Android)

Новости Формулы 1, календарь сезона 2026 (месяц + список), виджет на главный экран.
Всё время — по Москве (МСК).

## Как получить APK через GitHub
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая `.github`).
2. Откройте вкладку **Actions** → workflow **Build APK** (запускается сам при push, либо кнопка *Run workflow*).
3. Когда сборка зелёная — откройте запуск и скачайте артефакт **F1-Calendar-apk** (внутри `F1-Calendar.apk`).
4. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).

Чтобы APK появился в **Releases**: `git tag v1.0 && git push --tags`.

## Виджет
- Кнопка **«+ Виджет»** в шапке приложения предлагает добавить виджет на главный экран.
- Либо: долгое нажатие на рабочем столе → Виджеты → «F1 Календарь».
- Прозрачный фон, контур трассы, дата и время гонки по МСК, обратный отсчёт (дни/часы/минуты).

## Данные
- Календарь 2026 зашит в `data/Schedule.kt` (местные дата/время + часовой пояс → пересчёт в МСК).
- Новости: RSS f1news.ru, запасной — motorsport.com.
- Контуры трасс: [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) (MIT), скачиваются при сборке.
  Для новой трассы в Мадриде контура в базе нет — рисуется условная петля.
